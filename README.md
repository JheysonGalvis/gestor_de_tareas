### PROMPT CREAR TASK MANAGER ###
- Actúa como un senior frontend developer y product designer.
Crea una aplicación web tipo tablero Kanban (similar a Trello / Microsoft Planner)
para gestionar tareas de un proyecto, pero muy simple.
    - REQUISITOS FUNCIONALES:
        - Columnas fijas: "Pendiente", "En progreso", "Hecho"
        - Añadir tareas con título y descripción corta
        - Mover tareas entre columnas con drag & drop
        - Eliminar tareas
        - Guardar el estado en localStorage
        - No usar backend ni base de datos
    - REQUISITOS TÉCNICOS:
        - Usa SOLO HTML, CSS y JavaScript (sin frameworks, sin librerías externas)
        - Archivos separados: index.html, styles.css, script.js
        - Compatible con navegador moderno
        - Todo debe funcionar en local
    - REQUISITOS DE DISEÑO:
        - Diseño limpio, minimalista y moderno
        - Colores suaves, fondo claro
        - Tarjetas con bordes redondeados y sombra ligera
        - Tipografía sans-serif
        - Transiciones suaves al mover tarjetas
    - EXTRAS:
        - Botón para limpiar el tablero
        - Comentarios claros en el código
        - Explica al final cómo ejecutar la app en local
